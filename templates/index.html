Operator paper workflow

Use this checklist after a trip. Tick each step on paper before proceeding.

  1. Stabilize: restore safe power and confirm the printer/RIP is ready.
  2. Identify: locate the exact job and confirm the source file and printer/RIP metadata.
  3. Verify: review source integrity, latest checkpoint, interruption reason and evidence confidence.
  4. Choose: follow the highlighted Continue, Test first or Restart recommendation.
  5. Approve: record an explicit operator approval or rejection with a note.
  6. Validate: use a registration test when evidence is not physically confirmed.

Create a protected job

What this MVP proves

It creates an immutable source hash, stores print metadata, appends checkpoints and events, separates evidence confidence and generates a cropped continuation file with configurable overlap.

Not yet proven: exact physical printer position after a hard trip, universal RIP compatibility or automatic printer control.

Use a test image first. Do not connect this prototype to production printer control until the exact model and protocol are validated.
